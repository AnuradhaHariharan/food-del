# MERN Stack Food Ordering Application with Stripe Integration

This project is a full-stack food ordering application built using the MERN (MongoDB, Express.js, React, Node.js) stack. The application includes Stripe integration for secure online payments, enabling users to order food from various restaurants and make payments seamlessly. It is designed to be a simple, responsive, and feature-rich platform for both customers and restaurant owners.

🚀 **Live Demo:** [Frontend](https://food-del-1-o79x.onrender.com/) | [Admin](https://food-del-admin-fouz.onrender.com/add)  

## Features

- **User Authentication**: Secure sign-up/login with JWT authentication.
- **Food Ordering**: Users can browse menus, add items to their cart, and place orders.
- **Stripe Integration**: Seamless payment processing using Stripe for safe and reliable transactions.
- **Order History**: Users can view their order history and order status.
- **Admin Panel**: Admins can manage restaurants, menus, and orders through an intuitive interface.
- **Responsive Design**: Fully responsive UI for smooth user experience on desktop and mobile devices.

## Technologies Used

- **MongoDB**: NoSQL database to store user data, restaurant details, and order history.
- **Express.js**: Backend framework for building RESTful APIs.
- **React.js**: Frontend library to build a dynamic and responsive user interface.
- **Node.js**: Backend JavaScript runtime environment to handle server-side logic.
- **Stripe API**: Payment processing integration for secure and easy transactions.
- **JWT**: JSON Web Tokens for authentication and session management.

## Installation

1. **Clone the repository:**

```bash
git clone https://github.com/AnuradhaHariharan/food-del.git
cd food-del
```
2.**Set up backend:**

Navigate to the backend directory:
```bash
cd backend
```
Install dependencies:
```bash
npm install
```
Create a .env file and add your Stripe API keys and JWT_SECRET.

Start the server:
```bash
npm run server
```

3.**Set up frontend:**

Navigate to the frontend directory:
```bash
cd frontend
```
Install dependencies:
```bash
npm install
```
Start the front end:
```bash
npm run dev
```

4.**Set up Admin:**

Navigate to the frontend directory:
```bash
cd admin
```
Install dependencies:
```bash
npm install
```
Start the admin:
```bash
npm run dev
```
